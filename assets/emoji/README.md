Names for the Unicode 17.0 emoji catalogue, from Unicode emoji-test.txt and CLDR 48 annotations
(including annotationsDerived) in 140+ locales. The exact list is in languages.txt. Translation
coverage varies by locale. Sequences retain emoji presentation selectors. Unambiguous English
and Russian search keywords and a few common spoken aliases supplement the names.

Sources:

- https://www.unicode.org/Public/17.0.0/emoji/emoji-test.txt
- https://github.com/unicode-org/cldr-json/tree/48.0.0

Regenerate from the repository root with `node scripts/generate-emoji.mjs` (Node 22+).
The bundled TSV is included at compile time; builds and dictation require no network access.
Unicode data is distributed under the adjacent Unicode-3.0 license.
